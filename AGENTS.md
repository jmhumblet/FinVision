# Agent Guidelines

## Repository Understanding
This repository uses the Conductor framework. Agents must refer to the documentation and specifications located in the `/conductor` directory to understand the project structure, product definition, and workflow.

## Workflow Rules
### Ideation
New product ideas must be tracked as GitHub Issues with the label `status: idea`.

### Active Work
When an issue is selected for development, change its label to `status: active`.

### Source of Truth
`/conductor/product.md` remains the high-level guide; ensure it is kept up to date when features are shipped.
